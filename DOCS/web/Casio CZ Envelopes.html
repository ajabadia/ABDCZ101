Casio CZ Envelopes

2012-06-29

Casio CZ 8-Stage Envelopes

One of the interesting features of Casio CZ synthesizers is the envelopes that can be applied to each sound section. They were advanced for their time (mid 1980’s) and are still fun to use. In this section, I hope to describe the envelope data more fully and accurately, and to dispel a popular myth about CZ synthesizers.
